# nibbanahelp

Day-by-day diary of attaining nibbana — real journeys, real tensions, and AI guidance that gets better as the database grows.

## The idea

Nibbana is only attained **now**. Not after the debt is paid, the addiction is quit, or the psyche is sorted. The path is walked *through* the tensions, not around them.

This repo collects:

1. **Diary entries** (`entries/`) — dated, honest logs from the path. Day 1, day 2, …
2. **Tensions** (`tensions/`) — the specific knots each diarist is working with. The AI reads these to understand where someone actually is.
3. **Roots mapping** (`roots/`) — modern behaviours mapped to greed, hatred, delusion. Advanced mode: full Abhidhamma.
4. **Guidance** — advice grounded in real journeys, not abstractions. As the database of journeys grows, the guidance sharpens.

## How it works

- Anyone can start a diary: copy `entries/_template.md`, write honestly.
- Tensions are first-class: name them plainly (debt, addiction, shame, …). No performing enlightenment.
- Over time the corpus becomes training context: an AI that has read a hundred real journeys gives better advice than one that has read a hundred sutras about journeys.

## Structure

```
entries/     dated diary entries (day-01-*.md)
tensions/    tension records, one file per tension
roots/       greed / hatred / delusion + modern behaviour mapping
schema/      data shapes for entries and tensions
```
